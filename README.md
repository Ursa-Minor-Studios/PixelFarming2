Pixel Farming 2 is a 2D Pixel based farming game in development with the goal of building a farm on the moon and managing its resources to keep colonists alive and fed.

To learn more about the game itself, visit the [wiki](https://github.com/Ursa-Minor-Studios/PixelFarming2/wiki). The rest of this file goes over the project and development.

Pixel Farming 2 is my third game I've ever made, it's a sequel to Pixel Farming meant for me to improve on the mechanics that I learned how to do in the prequal.
